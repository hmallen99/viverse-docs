# Profiling and Testing 3D Web Experiences

## Core Browser Profiling Tools

### Overview of Tools

Performance Profiling:

* [Chrome](https://developer.chrome.com/docs/devtools/performance/overview)
* [Chrome Tracing](https://www.chromium.org/developers/how-tos/trace-event-profiling-tool/)
* [Safari](https://support.apple.com/guide/safari-developer/performance-overview-devf7aaca927/mac)
* [Firefox](https://profiler.firefox.com/docs/#/)
* [Edge](https://learn.microsoft.com/en-us/microsoft-edge/devtools/performance/overview)

Debugging:

* [Chrome](https://developer.chrome.com/docs/devtools/javascript)
* [Firefox](https://firefox-source-docs.mozilla.org/devtools-user/debugger/index.html)
* [Safari](https://support.apple.com/guide/safari-developer/debugging-overview-devd24689f72/mac)
* [Edge](https://learn.microsoft.com/en-us/microsoft-edge/devtools/javascript/)

Networking and Asset Loading Profiling:

* [Chrome Lighthouse](https://developer.chrome.com/docs/devtools/lighthouse)
* [Chrome Network Profiling](https://developer.chrome.com/docs/devtools/network/overview)
* [Firefox Network Profiling](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/index.html)
* [Edge Network Profiling](https://learn.microsoft.com/en-us/microsoft-edge/devtools/network/)

Device Emulation:

* [Chrome Device Emulator](https://developer.chrome.com/docs/devtools/device-mode/)
* [Firefox Device Emulator](https://firefox-source-docs.mozilla.org/devtools-user/responsive_design_mode/index.html)
* [Edge Device Emulator](https://learn.microsoft.com/en-us/microsoft-edge/devtools/device-mode/)

WebXR Emulation:

* [Meta Immersive Web Emulator](https://developers.meta.com/horizon/blog/webxr-development-immersive-web-emulator/)
* [Edge Plugin](https://microsoftedge.microsoft.com/addons/detail/immersive-web-emulator/hhlkbhldhffpeibcfggfndbkfohndamj)
* [Chrome Plugin](https://chromewebstore.google.com/detail/immersive-web-emulator/cgffilbpcibhmcfbgggfhfolhkfbhmik?pli=1)

Remote Inspection:

* [Chrome Remote Debugging](https://developer.chrome.com/docs/devtools/remote-debugging/local-server)
